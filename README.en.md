# Nivalis

Personal blog: https://blog.pureastar.top

The production branch is `blog`. Use Node.js22.22.0, `npm ci`, `npm run check`, then `SITE_URL=https://blog.pureastar.top npm run build`. Output: `dist`.

Content and settings are saved to Git manually. Never commit private drafts to this public repository.

Based on [Astro Whono](https://github.com/cxro/astro-whono); upstream MIT and font licenses retained.
